Acesta este un program realizat in Python(respectiv PYQT5).
Subiect: O spalatorie de tip SelfWash mai avansata!
Versiune Python : Python 3.13
Editor: Visual Studio Code

Mentiune: Daca nu aveti instalat PYQT5 puteti sa-l instalati din terminalul din Visual Studio Code utilizand comanda : pip intall pyqt5

Instructiuni: 
!! Utilizati tot Visual Studio Code pentru deschiderea fisierului Self_Wash.py(altfel imaginiile/ttf-ul nu se va incarca!)

Pasul 1. O sa fiti intampinati de prima pagina unde va trebui sa alegeti ce tip de autovehicul aveti(fiind versiunea Beta, nu exista momentan nicio diferenta)
Pasul 2. O sa vi se deschide cea de a 2 a pagina in care sunteti nevoiti sa apasati butonul "Apasa-ma" sau Close.
Pasul 3. Cititi toate detaliile care apar in partea stanga(Acelea sunt niste instructiuni despre ce face fiecare buton din program). 
In cazul in care ati inchis accidental legenda o puteti redeschide apasand butonul "Info"

Mentiuni: La nivelul intregului program veti gasi informatii despre modul de utilizare al intregului program!
